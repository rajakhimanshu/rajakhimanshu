### Selected work

| | What it is | The interesting part |
|---|---|---|
| **[GrowEdge Capital](https://www.growedgecapital.com)** | An investment-operations platform handling real client money | Built solo, in production 34 days after the first commit. An audit found 8 engines doing overlapping money maths; I merged them into one. |
| **[Kapsee](https://kapsee.in)** | Hinglish captions for Indian creators | Two speech-recognition providers, so one takes over if the other fails, and captions that stay in sync even on uneven phone footage. |
| **[GrowEdge Marketing Studio](https://github.com/rajakhimanshu/growedge-marketing-studio)** | Promo videos made from code | A web page animated frame by frame and captured in 4K by a headless browser. 398 scenes, 236 tests. |
| **[Quant Research Lab](https://github.com/rajakhimanshu/quant-research-lab)** | A lab built to kill trading ideas | 250 hypotheses, each frozen before its result is seen. One passed at p = 0.00017, then failed on unseen data. Never retuned. |
| **8+ Expert Advisors** | Trading systems on MT5 | Built and forward-tested across 2025 and 2026, from trend-following to scalping. |
| **Confidential build** | A real-time system spanning a PC, browser and phone | One set of rules kept in agreement across all three, built on modern .NET. |
